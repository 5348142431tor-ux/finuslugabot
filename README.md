# FinuslugaBot

Версия: `2.0.1`

Telegram-бот для работы с Google Sheets, Telegram Business и обменными заявками.

Что осталось:
- `/start` регистрирует чат в таблице.
- `/summa` и `/сумма` показывают ненулевые остатки по валютам.
- `/kurs` и `/курс` читают все столбцы, где в названии есть `rate`.
- В личке арифметические выражения можно писать сразу, например `100+25 usd` или `/100руб`.
- В группах арифметические выражения записываются только если есть обращение к боту, например `@FinUslugaTR_bot 100+25 usd`.
- `=...` позволяет передать готовое число вручную.
- OCR чеков по фото и изображениям: бот распознаёт сумму, просит подтверждение и после этого списывает её в таблицу.
- Бот сохраняет историю сообщений, примеры стиля и вложения по чатам в папку `CHAT_DATA_DIR`.

Примеры:
- `@FinUslugaTR_bot 100+25 usd`
- `@FinUslugaTR_bot 15000-350 rub`
- `@FinUslugaTR_bot =245.5 eur`

## Запуск
1. Установи зависимости: `pip install -r requirements.txt`
2. Скопируй `.env.example` в `.env` и укажи:
   - `TELEGRAM_TOKEN`
   - `GOOGLE_APPLICATION_CREDENTIALS`
   - `SPREADSHEET_KEY` или `SPREADSHEET_NAME`
   - `WORKSHEET_NAME` при необходимости
3. Запусти бота:
   - `python -m bot_app.main`
   - или `./run.sh`

## Версии и откат

## Таблица
Бот использует лист с базовыми колонками:
- `communication_style`
- `chat_id`
- `chat_name`
- `user`
- `expression`
- `result`
- `timestamp`

Для валют бот поддерживает и создаёт колонки:
- `result_USD`
- `result_USDT`
- `result_RUB`
- `result_EUR`
- `result_TRY`
- `result_KZT`

Команда `/kurs` читает из строки текущего чата любые столбцы, в названии которых есть `rate`.

Лист `Настройка` используется для управляемых приветствий:
- колонка `A`: `key`
- колонка `B`: `value`
- колонка `D`: `incoming_text`
- колонка `E`: `reply_text`
- ключи:
  - `greeting_Деловой`
  - `greeting_Дружеский`

Автоответы на благодарность задаются парами в колонках `D/E`.

## OCR чеков
- В личном чате чек можно отправлять сразу.
- В группе фото нужно отправлять с упоминанием бота в подписи.
- После распознавания бот предлагает кнопки `Верно` и `Исправить`.
- При ручном исправлении сумму нужно прислать цифрами, например `12345.67`.

## История чатов
- История хранится в `CHAT_DATA_DIR/<chat_id>/history.jsonl`.
- Профиль чата хранится в `CHAT_DATA_DIR/<chat_id>/chat_profile.json`.
- Примеры твоего стиля хранятся в `CHAT_DATA_DIR/<chat_id>/style_examples.jsonl`.
- Память обменных паттернов хранится в `CHAT_DATA_DIR/<chat_id>/exchange_patterns.jsonl`.
- Вложения сохраняются в `CHAT_DATA_DIR/<chat_id>/attachments/`.
