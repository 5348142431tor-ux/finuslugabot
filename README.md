# FinuslugaBot

Базовый Telegram-бот на Node.js с использованием [Telegraf](https://telegraf.js.org/).

## Быстрый старт

1. Склонируйте репозиторий и перейдите в каталог `FinuslugaBot`.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Скопируйте `.env.example` в `.env` и пропишите токен бота:
   ```bash
   cp .env.example .env
   ```
4. Запустите бота:
   ```bash
   npm run start
   ```

Команда `npm run dev` запускает бот с `nodemon` и автоматически перезапускает его при изменении файлов.

## Возможности
- `/start` — приветствие.
- `/help` — список команд.
- `/ping` — проверка связи.
- Эхо-ответ на произвольный текст.

| Имя       | Описание                         |
|-----------|----------------------------------|
| BOT_TOKEN | Telegram Bot Token из @BotFather |
