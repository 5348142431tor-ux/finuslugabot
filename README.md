# FinuslugaBot (math-bot)

Telegram-бот, который принимает сообщения (формулы, чеки, вопросы), считает сумму операций и синхронизирует их с Google Sheets. После обновления **1.1.0** бот умеет отдавать «живые» диалоги в операторскую супергруппу: любой текст без суммы автоматически пересылается в отдельную тему, а ответы операторов возвращаются пользователю от имени бота.

## Возможности
- `/start` регистрирует чат в таблице и показывает подсказку.
- `/сумма` — выводит ненулевые итоги по валютам USD/USDT/RUB/EUR/TRY.
- `/курс` — читает столбцы `rate` из строки текущего чата.
- `/sum` (англ.) и арифметические выражения — записывают результаты в колонку соответствующей валюты.
- `=...` — можно передать готовый результат (бот возьмёт число после `=`).
- OCR чеков (фото/PDF). В группах нужно упоминать бота в подписи.
- Любой текст без цифр → пересылка в операторский форум-чат, создание темы «Имя (ID)» и обратные ответы.

## Быстрый старт
1. Склонируй репозиторий и перейди в каталог `FinuslugaBot`.
2. Установи зависимости: `pip install -r requirements.txt` (Python 3.11+).
3. Скопируй `.env.example` в `.env`, пропиши:
   - `TELEGRAM_TOKEN`
   - `SPREADSHEET_KEY`, `WORKSHEET_NAME`
   - `SUPPORT_CHAT_ID` (forum supergroup ID)
   - путь к Google Service Account JSON (по умолчанию `creds/service-account.json`).
4. Помести JSON сервисного аккаунта в `creds/service-account.json` и выдай доступ к Google Sheet.
5. Запусти бота: `python bot.py` или через Docker `docker compose up --build -d`.

## Конфигурация
- `SUPPORT_CHAT_ID` — супергруппа с включёнными темами, куда бот будет слать обращения клиентов.
- `SUPPORT_TOPICS_FILE` — файл с привязками `user_id → thread_id` (по умолчанию `support_topics.json`, в репозитории игнорируется).
- `RECEIPTS_DIR` — куда сохранять входящие чеки/фото для диагностики.
- `SETTINGS_WORKSHEET` — лист с настройками (по умолчанию `Настройка`, структура: колонка A = ключ, колонка B = значение).
- `LOG_WORKSHEET` — лист журнала событий (по умолчанию `Лог`, колонки: timestamp, chat_id, client_name, topic, event).

## Вкладка "Курсы"

Чтобы обновить лист с котировками (пример JSON выше), используй скрипт:

```bash
python scripts/update_rates.py path/to/rates.json
```

Скрипт читает `GOOGLE_APPLICATION_CREDENTIALS`/`SPREADSHEET_KEY`, создаёт вкладку `Курсы` (можно переопределить через `RATES_WORKSHEET`) и записывает пары в формате `PAIR покупка/продажа`.
